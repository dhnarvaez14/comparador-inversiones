# Comparador de Inversiones

Herramienta pedagógica para evaluar y comparar dos inversiones. El estudiante digita los datos iniciales de cada empresa; la app estima el estado de resultados y el flujo de caja libre (FCL), calcula los indicadores de evaluación financiera y ayuda a decidir en cuál invertir.

- Indicadores: VPN, TIR, relación beneficio/costo, índice de rentabilidad (IR), VAUE, período de recuperación (PRI) y PRI descontado.
- Comparación lado a lado, con la TIR incremental para decidir entre inversiones de distinto tamaño.
- Sensibilidad del VPN frente a la TMRR de 5 % a 20 %, con gráfico y punto de cruce.
- Escenario con crecimientos y escenario sin crecimiento.
- Lectura guiada de cada indicador para contrastar con el análisis del estudiante.

Funciona completamente en el navegador: no usa servidor. Guarda los datos digitados solo en el navegador de quien la usa.
